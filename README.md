# 🌲 Random Forest Classification on Synthetic Dataset

## 📌 Overview
This project demonstrates the use of the **Random Forest classifier** on a synthetic dataset generated using `make_classification` from scikit-learn.

The goal is to understand **ensemble learning**, **feature importance**, and **model evaluation** in a controlled environment.

---

## 📂 Dataset
- Synthetic dataset generated using `make_classification`
- 1000 samples, 10 features
- 5 informative features
- Binary classification problem

---

## ⚙️ Algorithm Used
### Random Forest Classifier
- Ensemble of decision trees
- Reduces overfitting
- Handles non-linear relationships
- Provides feature importance

---

## 🧪 Methodology
1. Generate synthetic dataset
2. Train-test split
3. Train Random Forest model
4. Evaluate using accuracy and confusion matrix
5. Analyze feature importance

---

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook

---
📈 Results
---

Achieved high accuracy on test data

Identified important features

Demonstrated ensemble learning benefits

Stable performance across runs

Conclusion
---
This project demonstrates the fundamentals of Random Forest and ensemble learning using a clean, reproducible synthetic dataset.
